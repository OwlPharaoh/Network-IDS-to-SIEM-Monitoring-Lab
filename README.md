# Wazuh-SIEM-Lab
A hands-on SIEM lab using Wazuh, Sysmon, and simulated attacks across virtual machines

## Lab Setup
- Wazuh Manager on UTM (Ubuntu Server 24.04 LTS on Mac)
- Windows Server 2025 and Kali Linux via Hyper-V (Windows host)
- Agents + sysmon configured
- Logs collected, attacks simulated

## Key Files
- '01-agent-setup.md': Setup and registration of agents
- '02-log-baseline-analysis.md': Observations from logs
- '03-simulated-attacks.md': Triggered alerts and analysis
